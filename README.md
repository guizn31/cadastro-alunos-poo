# cadastro-alunos-poo

### README — Manual de uso do sistema de cadastro de alunos EducaTech
## 1. Sobre o Sistema:
## O sistema de cadastro de alunos, Educa tec, está desenvolvido em Python, utiliza uma biblioteca Tkinter para a interface gráfica e para o banco de dados  usa-se SQLite.

## O objetivo: 
## Facilitar o registro dos alunos;
## Facilitar consulta
## Efetuar boas atualizações e exclusões de informações dos alunos de uma escola.

## 2. Requisitos do Sistema:
## Antes de executar o sistema, verifique se você tem os seguintes itens instalados:
## Python 3.10 ou superior;
## Biblioteca Tkinter;
## Biblioteca SQLite3.

## 3. Como Executar o Sistema?
## Baixe ou copie o projeto em uma pasta no computador;
## Abra o terminal (ou prompt de comando) e navegue até a pasta do projeto:
## cd caminho/para/sistema_cadastro
## Execute o programa principal:
## python main.py
## O sistema abrirá uma janela gráfica em Tkinter com o formulário de cadastro.

## 4. Como Usar a Interface?
## Na tela principal, você verá os seguintes campos e botões:
## Label: Nome (insira seu nome completo);
## Label: CPF (insira seu CPF completo);
## Label: Data de nascimento (insira sua data de nascimento);
## Label: Status (insira seus status de aluno, por opção de ativo[indo para a escola frequentemente], ou inativo [não está indo para a escola frequentemente]);
## Botão: Cadastrar (guarda todos os seus dados no banco de dados da plataforma);
## Botão: Atualizar (atualiza os dados do aluno que foram modificados, com base de referência pelo CPF);
## Botão: Excluir (Exclui todos dados do aluno com referência pelo CPF);
## Busca filtrada: busca de dados pelo nome do aluno;
## Enquete de filtragem: alunos ativos ou inativos.
